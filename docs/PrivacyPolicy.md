# Privacy Policy - Lexicon Master

**Last Updated:** July 4, 2026

## 1. Introduction

Lexicon Master ("the Service") is a multilingual dictionary game platform designed for village communities. This Privacy Policy explains how we collect, use, store, and protect your personal information in compliance with the General Data Protection Regulation (GDPR) and other applicable privacy laws.

## 2. Data Controller

**Data Controller:** Lexicon Master  
**Contact:** privacy@lexicon-master.com  
**EU Representative:** For GDPR matters, please contact us at gdpr@lexicon-master.com

### 3.1 Personal Information
- **Email Address:** Required for account creation and authentication
- **Display Name:** User-chosen name for profile identification
- **Language Preferences:** Selected interface language(s)
- **Game Statistics:** Scores, matches played, achievements (aggregated, anonymized)

## 6. Data Security Measures

### 6.1 Encryption
- **Data at Rest:** AES-256 encryption for all sensitive data
- **Data in Transit:** TLS 1.3 for all communications
- **Crypto-Shredding:** Encryption keys can be destroyed to permanently delete data

### 6.2 Storage Location
- **EU-Based Storage:** All data stored in European Union data centers
- **Firebase EU Region:** Firestore database hosted in europe-west1
- **Backup Security:** Encrypted backups with controlled access

### 6.3 Access Controls
- **Role-Based Access:** Minimum necessary access principle
- **Authentication:** Multi-factor authentication for admin access
- **Audit Logging:** All data access logged and monitored

## 7. Data Retention

### 7.1 Active Accounts
- **Personal Data:** Retained while account is active
- **Game Statistics:** Retained indefinitely for progress tracking
- **Event Logs:** Retained for 2 years, then anonymized

### 7.2 Inactive Accounts
- **Definition:** No login for 24 consecutive months
- **Action:** Data anonymization after 26 months of inactivity
- **Notification:** Email notice sent prior to anonymization

### 7.3 Deleted Accounts
- **Immediate Deletion:** Personal data deleted within 30 days
- **Crypto-Shredding:** Encryption keys destroyed for permanent deletion
- **Exception:** Anonymized statistics may be retained for service improvement

## 8. Your GDPR Rights

### 8.1 Right to Access (Article 15)
You can request a copy of all personal data we hold about you.

**Process:**
- Submit request to gdpr@lexicon-master.com
- Receive response within 30 days
- Data provided in machine-readable format

### 8.2 Right to Rectification (Article 16)
You can request correction of inaccurate personal data.

### 8.3 Right to Erasure (Article 17)
You can request deletion of your personal data ("Right to be Forgotten").

**Process:**
- Submit deletion request to gdpr@lexicon-master.com
- Verify identity to prevent unauthorized deletions
- Data deleted within 30 days (except legal requirements)

### 8.4 Right to Restrict Processing (Article 18)
You can request limitation of processing in certain circumstances.

### 8.5 Right to Data Portability (Article 20)
You can request your data in a structured, machine-readable format.

**Available Data:**
- Game statistics and progress
- Event logs and achievements
- Profile information (encrypted)

### 8.6 Right to Object (Article 21)
You can object to processing based on legitimate interests.

### 8.7 Rights Related to Automated Decision-Making
- No fully automated decisions affecting users
- All game recommendations based on transparent algorithms
